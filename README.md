| GitHub 仓库文件总大小显示 | 在 GitHub 仓库标题处显示仓库文件总大小 | [![](https://img.shields.io/badge/install-v0.1.3-red)](https://r4p0.github.io/UserScript/github_repo_size_display.user.js) |
